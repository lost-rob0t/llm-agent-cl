* Principle

“Production ready” and “feature parity” are observed release properties, not architecture adjectives. The project must not claim either until their automated evidence is green for a release candidate.

* Deterministic core/provider tests

- canonical message/content/usage/profile round trips;
- provider request/response fixtures;
- config precedence and secret redaction;
- JSON Schema tool validation;
- tool-call correlation and parallel ordering;
- structured-output validation/fallback;
- middleware ordering and error propagation;
- model capability caching/staleness;
- graph routing, reducers, Send/Command, recursion limits and subgraphs;
- checkpoint serialization/resume/corruption handling;
- pending-write recovery;
- interrupt/resume/time-travel semantics;
- long-term store behavior.

* Streaming torture tests

Replay fixture streams across every byte boundary plus randomized chunking:

- SSE comments/keepalives;
- multiline data;
- fragmented UTF-8;
- fragmented tool JSON;
- structured-output partial JSON;
- duplicate/late usage;
- cancellation;
- consumer failure/backpressure;
- provider error after successful tokens;
- premature EOF.

* Transport conformance

Run equivalent behavioral suites against Dexador sync and the approved hardened =lost-rob0t/carrier= async adapter where semantics overlap. A provider must not need separate business logic for each transport.

Carrier itself has its own stricter security/lifecycle release gate from Design 006: TLS chain+hostname fixtures, cancellation/deadline races, connection reuse/shutdown, binary/streaming bodies, redirect credential safety and resource/leak tests.

* Live OpenRouter tests

Credential-gated tests are separate from deterministic CI and use bounded token/cost budgets. Cover:

- non-stream chat;
- streaming chat;
- tool call;
- structured output;
- multi-turn state at llm-agent layer;
- model discovery/capability profile;
- embeddings single/batch;
- cancellation where downstream behavior is observable;
- representative error/rate-limit paths where safely reproducible.

Absence of credentials skips only live tests.

* Graph/agent conformance

Required scenarios:

- deterministic reducer conflicts/order;
- conditional routes;
- dynamic Send map/reduce;
- Command update+routing;
- bounded parallel supersteps;
- failed sibling task + persisted successful pending writes;
- interrupt/resume;
- subgraph checkpoint namespaces;
- checkpoint history/replay/fork;
- high-level model/tool loop with one and parallel tools;
- budgets/recursion/cancellation;
- typed graph/model/tool event streams.

* Retrieval parity tests

First-major-milestone release evidence includes:

- document/provenance behavior;
- text/JSON/CSV/HTML/HTTP representative loaders;
- lazy loader cancellation and limits;
- character/recursive/token splitter edge cases;
- deterministic fake and live OpenRouter embeddings;
- embedding cache;
- store operations;
- exact in-memory vector ranking/filtering;
- retriever sync/async/batch;
- complete load -> split -> embed -> store -> retrieve -> generate workflow;
- retrieval used as graph node and agent tool.

* MCP interoperability

- current 2026-07-28 stdio fixture server/client;
- current Streamable HTTP JSON/SSE fixture;
- tool/resource/prompt discovery;
- structured/multimodal tool results;
- cancellation;
- server export round trip;
- selected older protocol fixture proving compatibility or explicit rejection.

* Fault injection

Inject DNS/TLS failures, connect/read/deadline expiry, HTTP 429/5xx, malformed JSON, mid-stream disconnect, repeated tool failure, checkpoint failure, cancellation races, vector dimension errors, embedding provider errors, MCP process exits and retry exhaustion. All require typed terminal outcomes and deterministic cleanup.

* Portability/API compatibility

SBCL is the initial reference production environment. Additional Common Lisp implementations become supported only with CI evidence across their relevant dependency paths. Public APIs use semantic versioning and migration/deprecation notes for breaking changes.

* Observability

Structured hooks/events cover request/model/tool/retrieval/graph/checkpoint/MCP operations, retries, state transitions, token usage and latency. No hosted tracing vendor is required. Secrets are redacted before observers see payloads.

* First-major-milestone release gate

A parity-complete production milestone requires:

1. deterministic suites green;
2. Carrier hardened release gates green and pinned;
3. live OpenRouter integration green for the release candidate when credentials are available;
4. graph/agent, retrieval and MCP matrices green;
5. no unresolved P0/P1 correctness/security defects;
6. documented provider/model capability matrix;
7. documented Lisp/dependency support matrix;
8. explicit unsupported-feature behavior rather than silent omission.
