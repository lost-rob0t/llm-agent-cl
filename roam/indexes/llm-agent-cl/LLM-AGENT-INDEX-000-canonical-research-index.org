* Scope

This index tracks canonical research for a production-oriented Common Lisp library with LangChain + LangGraph class capabilities, OpenRouter as the first provider, sync/async HTTP, streaming, tools, multi-turn state, and MCP. It explicitly does not authorize runtime implementation.

* Current blockers

1. No runtime design is approved.
2. The production async backend still needs a design choice between a hardened Carrier path and a small libcurl-multi client; stock Carrier is not acceptable unchanged because current TLS verification is disabled and cancellation/connection-reuse contracts are incomplete.
3. OpenRouter provider-native structured-output details need a field-level conformance pass before implementation.

The earlier “Lobster” identity gap is closed: Carrier is the verified native async Common Lisp HTTP client used as the reference implementation for research.
