* Scope

This index tracks canonical research for a production-oriented Common Lisp library with mandatory LangChain + LangGraph behavioral feature parity, OpenRouter as the first provider, Dexador synchronous HTTP, maintained =lost-rob0t/carrier= asynchronous HTTP, streaming, tools, structured output, multi-turn state, graphs/checkpoints/interrupts/time travel, MCP, and the full first-milestone retrieval/data-plane family.

Research is now complete enough to produce an implementation-ready design set for maintainer review. This does **not** authorize runtime implementation.

* Maintainer decisions already incorporated

- LangChain + LangGraph behavioral parity is required.
- Documents/loaders/splitters/embeddings/stores/vector stores/retrievers/RAG belong in the first major parity milestone.
- OpenRouter is the first provider.
- Quick-test/REPL scoped/process/environment configuration conveniences are allowed; explicit configuration remains supported and overrides defaults.
- MCP research/scope 004 is accepted as the research baseline.
- =lost-rob0t/carrier= is the async HTTP fork the project will maintain and harden.
- The earlier automatic libcurl fallback is superseded; changing away from Carrier requires a new maintainer decision.

These decisions approve research direction, not the new implementation designs.

* Remaining blockers before code

1. The six design documents remain pending maintainer review/approval.
2. Runtime implementation is explicitly not authorized until applicable designs are approved.
3. Carrier hardening cannot begin until Design 006 is approved; after implementation it must satisfy its independent security/lifecycle release gates before llm-agent-cl treats it as production async transport.

The earlier blockers around “Lobster,” provider-native structured-output field research, retrieval milestone placement and async backend selection are closed by research 002/003/007/008 and explicit maintainer decisions.
