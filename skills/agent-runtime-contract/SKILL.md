# Agent Runtime Contract

Research both a high-level agent loop and a low-level composable graph API. Required semantics include explicit state, deterministic and model-driven nodes, conditional routing, subgraphs, parallel branches, checkpoint interfaces, resumability, interrupts, human approval hooks, step/event streaming, recursion/step limits, cancellation, and middleware. These remain embeddable library constructs, not a hosted harness.
