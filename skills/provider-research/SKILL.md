# Provider Research

For each provider record authentication, endpoints, request/response schema, model discovery, capability metadata, tools, structured output, multimodality, streaming, usage, reasoning metadata, cancellation, errors, rate limits, retries, idempotency ambiguity, privacy/logging, and conformance fixtures. Provider-specific extensions must be preserved without becoming core assumptions.
