# Save Research

## Procedure
1. Search for an existing canonical node before creating one.
2. Use primary sources and record retrieval date.
3. Add stable ID, title, description, status, filetags, approval table, changelog, sources, unresolved questions, and glossary.
4. Separate verified facts from recommendations and assumptions.
5. Link the project index in the same change.
6. Run sync and document validation.

Never claim approval or implementation from a research merge.
