# Feature Parity

Build a capability matrix from current official LangChain/LangGraph documentation. Measure semantic capabilities rather than copying Python APIs. Track model/message abstraction, multimodal content, sync/async invoke, batch, token/event streaming, tools, structured output, middleware, multi-turn state, retries/fallbacks, persistence, interrupts, graph/subgraph composition, memory, observability hooks, and MCP. Record gaps explicitly.
