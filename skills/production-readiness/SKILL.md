# Production Readiness

Require deterministic provider fixtures, live credential-gated integration tests, transport parity tests, fragmented streaming fixtures, fault injection, cancellation/deadline tests, retry/idempotency tests, MCP compatibility fixtures, schema validation, portability checks, zero-secret logging tests, API versioning, observability hooks, and documented unsupported capability behavior. A provider failure must never collapse into an untyped string error.
