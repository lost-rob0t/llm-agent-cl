# Tool Contract

Research JSON Schema input/output, stable tool-call IDs, multiple and parallel calls, tool result correlation, sync/async tool execution, retries, timeout/cancellation, authorization hooks, tool errors, model-visible errors, and provider-native versus tool-mediated structured output. Tools are caller-provided capabilities, not hidden global actions.
