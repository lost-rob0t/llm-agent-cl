# Model Contract

Research a canonical model request/result vocabulary: roles, typed content blocks, tool calls/results, usage, finish reasons, reasoning/citations, provider metadata, structured output, errors, and stream chunks. Preserve unknown provider extensions in an explicit extension field rather than flattening them into core types.
