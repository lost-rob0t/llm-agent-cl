# Transport Contract

Dexador is the required synchronous transport. The requested async `Lobster` dependency must be positively identified before implementation. Research semantic equivalence across sync/async request execution, connection reuse, deadlines, cancellation, TLS, proxies, headers, body streaming, retries, ambiguous submission, and resource cleanup. Keep SSE decoding above the HTTP adapter.
