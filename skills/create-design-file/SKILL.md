# Create Design File

Do not use this skill until the relevant research has explicit approval. A design must link its research basis, define library boundaries, public contracts, failure semantics, compatibility constraints, acceptance tests, migration/versioning policy, and unresolved dependencies. Do not turn `llm-agent-cl` into an application harness.
